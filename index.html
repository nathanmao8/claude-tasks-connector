Claude Tasks Connector

A personal tool built and used only by Nathan Mao. It is a small program that runs on my own computer and lets the Claude desktop app read and manage my own Google Tasks, so tasks I create with Claude appear in the Google Tasks app and Google Calendar.

What it does

  • Lists my task lists and tasks
  • Creates, edits, completes, moves and deletes tasks I ask it to

It is not offered to the public and has no other users.
