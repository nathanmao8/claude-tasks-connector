Privacy Policy

Claude Tasks Connector · last updated November 7, 2026

Claude Tasks Connector is a personal tool used only by its developer, Nathan Mao, with his own Google account.

Data accessed

With the Google Tasks scope (https://www.googleapis.com/auth/tasks), the tool reads and writes task lists and tasks in the signed-in account. It accesses no other Google data.

How data is used and stored

  • Task data is used only to carry out requests the account owner makes through the Claude desktop app.
  • The sign-in token is stored only on the owner's computer. No task data is stored by the tool or sent to any server operated by the developer.
  • Task content the owner asks Claude about is processed by Anthropic as part of the owner's Claude conversations, under Anthropic's own terms.
  • Data is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
